# Bridgestone × Okamoto · Taiwan-exclusive Wild Adventure Map (concept prototype)

A mobile-first landing page and interactive map app made for a creative pitch. **This is a concept prototype. It is not an official Bridgestone or Okamoto website and is not affiliated with or endorsed by either brand.**

- Static site: `index.html` with Tailwind (prebuilt `css/site.css`), `css/app.css`, vanilla JS (`js/app.js`) and Leaflet 1.9.4 (CDN).
- Real spots (coordinates from OpenStreetMap/Nominatim), real Bridgestone Taiwan tire models and official tire centers (bridgestone.com.tw). Routes were precomputed with OSRM.
- Simulated for the demo: privacy scores, "occupied" spots and Stealth Mode. Nothing is tracked and no location is shared.

Deep links: `#app`, `#peek=<id>`, `#spot=<id>`, `#route=<id>`, `#tires`, `#journey`, `#stealth`, `#taiwan`.
